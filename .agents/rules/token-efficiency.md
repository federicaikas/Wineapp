# Token Efficiency & Grouping Rule

- **Consumo Token Minimale**: Rispondi in modo ultra-sintetico ed essenziale.
- **Raggruppamento Modifiche**: Raggruppa ed esegui più modifiche insieme in un singolo passaggio/tool call invece di spezzettarle.
- **No Verification Polling/Build ad Ogni Modifica**: Non eseguire `npm run build` o `npx tsc` ad ogni singolo ritocco, ma solo a fine lavoro o quando espressamente richiesto.
